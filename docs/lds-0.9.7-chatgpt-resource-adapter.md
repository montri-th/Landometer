## เลือกวิธีที่ตรงกับงาน

- **ChatGPT Chat:** ผู้ดูแลอัปเดต plugin `landometer-design-system` ตัวเดิมด้วยแพ็กเกจนี้ แล้วตรวจสิทธิ์การติดตั้งของกลุ่มที่ใช้ LDS เปิด Chat ใหม่เพื่อทดสอบการอ่านไฟล์ แพ็กเกจมีชื่อและ version เดิม จึงไม่ควรติดตั้งซ้ำเป็นคนละตัว
- **ChatGPT Work:** ใช้ runtime 0.9.7 ที่ติดตั้งจริงและตรวจตำแหน่งไฟล์ก่อนรัน verifier ผลทดสอบล่าสุดยัง mount โครงสร้างแพ็กเกจเต็มเดิมหลังอัปโหลด adapter จึงยังไม่ยืนยันว่า Work รับโครงสร้าง adapter แล้ว อ่านขอบเขตผลทดสอบด้านล่าง
- **ChatGPT / Claude Project Source:** ใช้ normative ฉบับเต็มเดิม คู่กับ Product Add-on และ Location Profile ตามงาน ถ้ามีไฟล์ 0.9.7 ที่ตรงกับ [รายการปัจจุบัน](https://montri-th.github.io/Landometer/v0.9.7/project-source-0.9.7.md) อยู่แล้ว ไม่ต้องอัปโหลดใหม่เพราะการจัดแพ็กเกจนี้
- **Codex, Claude Code, Cowork และ Design:** ใช้ช่องทางและแพ็กเกจตาม [คู่มือติดตั้ง](https://montri-th.github.io/Landometer/v0.9.7/team-setup.md) เดิม การทดสอบ adapter ใน ChatGPT ไม่ยืนยันการเปิดใช้ในเครื่องมือหรือบัญชีอื่น

## ตรวจว่าอ่านของจริงได้

ใน session ใหม่ ให้เปิดสกิลที่ติดตั้ง แล้วอ่าน `release.json` และสเกล `water` กับ `count` จากไฟล์ประกอบ ส่งคืน anchors และ HEX เจ็ดระดับแยก light/dark พร้อมเปรียบเทียบทั้งสองชุด ค่าต้องตรงกันตามกฎ 0.9.7 งาน Location ให้ตรวจ `li.service_gap` และความหมายของค่าลบ ศูนย์ บวกด้วย

ถ้าระบบรันตัวตรวจได้ ให้รายงานผลที่รันจริง ถ้าอ่านไฟล์ได้แต่รันไม่ได้ ให้แยกสองสถานะนี้ ไม่ถือว่าเห็นชื่อสกิลแล้วจะอ่าน asset ได้ครบ และไม่ใช้การค้นเว็บแทนการทดสอบ package ที่ติดตั้ง

หากช่องทางนั้นยังเข้าถึงไฟล์ประกอบไม่ได้ ให้ใช้ normative จาก Project Sources โดยตรงและแจ้งข้อจำกัด อย่าเดาค่าสีจากชื่อหรือคำบรรยาย

## ผลทดสอบของช่องทาง

การทดสอบ Chat ใหม่วันที่ 1 ตุลาคม 2026 อ่าน release, records ของ count/water ทั้งสองธีม, service gap และกฎ normative ที่จำเป็นได้ ค่าที่ตอบกลับตรงกับต้นฉบับ แต่ Chat ไม่มี package ที่ mount เป็นไฟล์สำหรับรันตัวตรวจ จึงรายงานว่า **อ่าน resources ผ่าน · verifier execution ไม่พร้อม** ไม่อ้างว่ารันตรวจ package ใน Chat แล้ว

adapter ที่ดาวน์โหลดนี้ผ่านการตรวจในเครื่อง **9,768/9,768**; จำนวนต่างกันเพราะตรวจโครงสร้าง skill แบบ self-contained แทนจุดตรวจ manifest ของแพ็กเกจเต็ม ตรวจแยกแล้วว่า manifest ภายนอกคงเดิม ทั้งสองการตรวจยังรายงานคำเตือนด้าน hue และความคล้ายของ density รวม 65 รายการ ไม่ใช่ใบรับรองว่าทุกสีแยกออกจากกันได้สำหรับผู้ใช้ทุกคน
