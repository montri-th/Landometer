# ข้อความประกาศ LDS 0.9.6 สำหรับ Discord

ข้อความแยก LDS, ijji และ CityChat สำหรับคัดลอกส่งในช่องทีม

## 1. LDS — all teams

**ประกาศใช้ Landometer Design System 0.9.6**

ทีมที่ทำงาน Landometer / CityMETER ช่วยอัปเดตชุดที่ใช้ใน ChatGPT, Claude, Cowork, Design และ Code ให้เป็น 0.9.6 ครับ

รอบนี้ปรับ **gradient ทางเดียวครบ 14 ชุด** ให้มีสีหลักหัว–กลาง–ท้ายต่างเฉดชัดขึ้น เช่น **ครีม → เขียว → ฟ้า** เพื่อเห็นระดับข้อมูลบนแผนที่และกราฟได้ชัดขึ้น โดยยังไล่ความสว่างทางเดียว และ density ทุกตัวยังคงโทนร้อน

สเกลสองทาง สี categorical, brand voice, identity และ motif/animation สืบทอดจาก 0.9.5 ครับ

**เริ่มใช้**
• ChatGPT / Claude Project: ดาวน์โหลดและใส่ **LDS ฉบับเต็ม 0.9.6 เพียง 1 ไฟล์** ใน Project Sources / Files ไม่ต้องแนบ master 0.9.4 หรือ patch เพิ่ม
• งาน ijji / CityChat / CityWiki: เพิ่ม **Add-on แยกของผลิตภัณฑ์ที่จับคู่กับ LDS 0.9.6** รวมเป็น 2 ไฟล์ ดูโพสต์ผลิตภัณฑ์และหน้าดาวน์โหลด
• สำรองและนำ DS/Add-on รุ่นที่ถูกแทนที่ออกจากแหล่งอ้างอิง active เก็บ brief, research, data และหลักฐานธุรกิจเดิม
• Plugin / Cowork / Code / Design: อัปเดตชุดติดตั้งหรือ Design library ตามคู่มือของช่องทางนั้น แล้วเปิด session ใหม่

ตั้ง Project Instructions:
“ใช้ LDS 0.9.6 ฉบับเต็มที่แนบเป็นกฎกลางปัจจุบัน และ Add-on ของผลิตภัณฑ์ที่ตรงรุ่นเมื่อเกี่ยวข้อง อ่านค่าสีจากตารางจริง ไม่สร้าง gradient จากสีหัวท้ายเอง และตรวจชิ้นงานก่อนส่งมอบ”

**ดูสีและคู่มือ:** https://montri-th.github.io/Landometer/v0.9.6/
**ดาวน์โหลด Project Source:** https://montri-th.github.io/Landometer/v0.9.6/project-source-0.9.6.md
**Normative ฉบับเต็ม:** https://montri-th.github.io/Landometer/v0.9.6/normative/Landometer-Design-System-v0.9.6.md
**ติดตั้งแต่ละเครื่องมือและ assets:** https://montri-th.github.io/Landometer/v0.9.6/team-setup.md

ก่อนเริ่มงาน ลองให้ AI อ่านชื่อเอกสาร รุ่น และสีหลักสามสีของ count/light จากไฟล์จริงครับ การอัปเดต Project หนึ่งไม่อัปเดตทุกเครื่องมือหรือทุกบัญชีให้อัตโนมัติ ส่วนงานเก่าที่ล็อกรุ่น 0.9.5 ยังเก็บชุดเดิมไว้ตรวจย้อนหลังได้

## 2. ijji — separate product post

**ทีม ijji: อัปเดตเป็น LDS 0.9.6 + ijji Add-on**

Project ของ ijji ใช้ **2 ไฟล์คู่กัน** ครับ

1. **LDS 0.9.6 ฉบับเต็ม** — กฎกลาง สี ฟอนต์ อัตลักษณ์ และ motif/animation ที่ใช้ร่วมกัน
https://montri-th.github.io/Landometer/v0.9.6/normative/Landometer-Design-System-v0.9.6.md
2. **ijji Add-on 0.5.5 for LDS 0.9.6** — กฎเฉพาะ ijji และการจับคู่กับฐานใหม่
https://montri-th.github.io/Landometer/v0.9.6/normative/ijji-Add-on-v0.5.5-for-LDS-v0.9.6.md

ดาวน์โหลดใหม่ทั้งคู่ ใส่ใน Project Sources / Files ของ ChatGPT และ Claude แล้วตั้ง Instructions:
“ใช้ LDS 0.9.6 ฉบับเต็มเป็นกฎกลางคู่กับ ijji Add-on ที่แนบสำหรับกฎผลิตภัณฑ์ อ่านค่าจริงจากทั้งสองไฟล์ คง brand voice, identity และ motion ของ ijji ตาม Add-on หากพบกฎขัดกันให้ระบุข้อขัดแย้งก่อนสร้างงาน”

สำรองและนำ DS/Add-on ที่ถูกแทนที่ออกจากแหล่งอ้างอิง active โดยเก็บข้อมูลธุรกิจและ brief เดิม ไม่ต้องใช้ master 0.9.4 หรือไฟล์ DS รวมผลิตภัณฑ์ สำหรับ Cowork / Code ให้อัปเดตชุดติดตั้ง และ Design ให้อัปเดต library พร้อมตรวจสีที่นำเข้า

รอบนี้รับ gradient ทางเดียวสามสีจาก LDS ใหม่ ส่วนกฎ identity และ motion ของ ijji คงเดิมครับ เปิด session ใหม่และให้ AI ยืนยันว่าอ่านทั้งสองไฟล์ได้จริงก่อนเริ่มงาน

**คู่มือติดตั้ง:** https://montri-th.github.io/Landometer/v0.9.6/team-setup.md
**คู่มือ ijji:** https://montri-th.github.io/ijji/ijji-TH.dc.html
