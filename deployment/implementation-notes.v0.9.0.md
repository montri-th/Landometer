### `ui-20260821-01` — self-check card disclosure fold (2026-08-21)

**Defect (Observed fact, owner report from a desktop screenshot):** the `[KIT-01]`/`[SELFCHECK-01]` card rendered its full 19-row `sc-table` inline inside a multi-column card grid, so the card ran far past its row neighbours.

**Why the automated gates did not catch it (Observed fact):** no gate measures rendered card height or row-height parity. `validate-release` checks identity, tokens, bytes, and hashes; `check-gradient-contrast` samples colour; `check-scale-geometry` covers 36 scale-label cases; the experience-contract checker covers component contracts. None of them models "content longer than the container it was designed for". This is a coverage gap in the gate set, not a gate that passed something false.

**Fix:** the card now follows the rule its own neighbour states — `[DISCLOSURE-01]` answer-first, evidence one tap deep, and the media-ladder rule that overflow folds into an expander. An answer-first totals line (`15 pass · 2 n/a · 2 fail`, counted from the table, both fails being the recorded SC-02/SC-03 `[EXCEPTION-01]` entries) is followed by a `<details>` fold containing the 19 rows in a bounded `max-height: 320px` scroll container, so opening the fold cannot re-inflate the grid row. Self-check verdicts themselves are unchanged.

**Release mechanics:** governed colour, gradient, token source, and scale source are all unchanged, so this is a UI-only change: Color Set stays `color-srgb-04` and a new append-only artifact build `ui-20260821-01` plus pinned filename is minted. `ui-20260820-02` is preserved byte-for-byte and stays byte-verified by the validator and by the `pages.yml` post-deploy gate.

**Doctrine defect found and fixed in the same change:** `color-srgb-04`'s Colour Set baseline is the first baseline in this repository to survive into a second UI build. `validate-release.mjs` and `build-standalone-html.mjs` both asserted the baseline must be byte-identical to the *current* UI artifact, which contradicts the baseline's own recorded `integrityMode` ("never rewritten for a UI-only change"). Both tools now read a new registry field `mintedWithArtifactBuild` and verify the baseline against the build it was minted with (`ui-20260820-02`), leaving it byte-frozen. Without this the release could only have been shipped by wrongly rewriting a published immutable artifact or by wrongly minting a Colour Set for a change that touched no colour.
