# Landometer design work

Current default for new Landometer / CityMETER branded work: **DS 0.9.6**, Color Set **color-srgb-09**, owner distribution **v0.9.6-owner.1**. Read `plugins/landometer-design-system/skills/apply-landometer-design-system/SKILL.md` before creating or revising branded artifacts. Use bundled assets and exact scale tables. Preserve explicit historical pins and user-selected other systems.

Run `node tools/validate-release.mjs` before proposing release changes. Do not edit frozen inherited signed assets. Package integrity is separate from artifact conformance, accessibility, brand review and account installation. Report the checks actually performed. A local install does not activate ChatGPT or Claude workspace policies.

## Owner visual preference and rendered review

Do not introduce decorative bracket-shaped highlights or colored left rails on selected navigation, tabs, cards or callouts. Use restrained background, text weight and spacing; keep keyboard focus visible and preserve meaningful chart/table borders. This preference also applies when restoring historical layouts: do not restore a rejected treatment with archived CSS.

Review every newly added section in the rendered page, including Thai/English and narrow/desktop views. Package hashes, page overflow and palette checks do not prove that text is readable or non-overlapping. Do not reuse a named-grid component when its required slots or header badge are absent. Check heading width and sibling content overlap explicitly before publishing.
