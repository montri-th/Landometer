# Landometer design work

Current default for new Landometer / CityMETER branded work: **DS 0.9.5**, Color Set **color-srgb-08**, owner distribution **v0.9.5-owner.1**. Read `plugins/landometer-design-system/skills/apply-landometer-design-system/SKILL.md` before creating or revising branded artifacts. Use bundled assets and exact scale tables. Preserve explicit historical pins and user-selected other systems.

Run `node tools/validate-release.mjs` before proposing release changes. Do not edit frozen inherited signed assets. Package integrity is separate from artifact conformance, accessibility, brand review and account installation. Report the checks actually performed. A local install does not activate ChatGPT or Claude workspace policies.
