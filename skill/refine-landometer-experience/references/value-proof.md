# Value proof: Brand DNA and Brand Voice

## Brand DNA

Use the same synthetic work and facts in both states.

Show:

```text
before: generic object + weak evidence trail + broad action
after: concrete object + source/date/boundary/limitation + one useful action
```

Make `Clear`, `Grounded`, and `Energetic` observable outcomes:

- **Clear:** identify the work and the decision immediately.
- **Grounded:** keep source, date, place, boundary, and limitation with the result.
- **Energetic:** use a credible verb that helps the next person continue.

Keep the baseline readable. Its failure is missing meaning, not bad typography or contrast.

## Brand Voice

Show a complete rewrite, not only prohibited phrases.

Use this sequence only as far as the message needs:

```text
real person/place/object/work/decision
→ finding or change
→ consequence
→ evidence, status, and material limitation
→ next action or clean completion
```

Prefer exact nouns and direct verbs. Draft Thai and English independently from the same evidence record. Do not mirror sentence structure.

## Interaction

- Make the Before/After switch change content, metadata, and action—not only type size.
- Let the lens change the highlighted anatomy, not the underlying facts.
- Announce one concise summary through a polite live region.
- Use a 160–240 ms state transition; show the final state immediately under reduced motion.
